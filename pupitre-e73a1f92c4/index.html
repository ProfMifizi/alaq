Le pupitre

Ce que l'app signale — les drapeaux ⚑ des élèves et ce qu'elle détecte toute seule.

Connexion

La serrure n'est pas cette page : c'est la RLS de Supabase (« Row Level Security » — des règles écrites dans la base elle-même). Quiconque trouve cette adresse verra la porte, mais la base ne rend les tickets qu'à ton adresse e-mail vérifiée. Le code arrive sur prof.mifizi@gmail.com — la même mécanique que le studio des sons.

Chaque carte regroupe une signature — type + message (les nombres remplacés par N) + écran. C'est le dédoublonnage : mille élèves qui rencontrent le même bug font UNE carte avec un compteur, pas mille lignes. Et côté app, une même signature ne part qu'une fois par jour et par appareil.

Les drapeaux ⚑ : une élève a coché un motif dans l'app, qui a capturé toute seule l'écran, la version et l'appareil — on ne demande jamais à une élève de décrire un bug. C'est la table signalements, la même que le relevé en ligne de commande (qui reste en secours).

Pourquoi cette page n'est pas sur app.alaq.fr : le service worker de l'app y détourne TOUTE navigation (n'importe quelle adresse du domaine sert l'app) — c'est le même exil que le studio des sons, un projet Vercel séparé. L'adresse n'est pas le secret ; la RLS l'est.
« Copier pour Claude » copie le dossier complet du ticket (occurrences, journaux, appareils) — colle-le tel quel dans une session : tout le contexte y est.
« Écran bloqué » n'est pas détecté en v1 (décision du 31/08 : trop de faux positifs — une élève qui pose son téléphone y ressemble) ; « son absent » non plus, car l'app essaie volontairement plusieurs fichiers par son — le premier 404 est normal. Les deux viendront en v2, calibrés sur les vraies données.
